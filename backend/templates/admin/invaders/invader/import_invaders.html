Format du fichier

Une liste JSON d'invaders. Seuls name, lat, lng et points sont obligatoires :

[
  {
    "name": "PA_223", "lat": 48.848, "lng": 2.376, "points": 20,
    "status": "ok", "address1": "30 Rue Abel", "address2": "", "zip": "75012", "comment": "",
    "city": {"name": "Paris", "prefix": "PA", "country": "France"},
    "flashed_by": ["membre@example.org", {"email": "autre@example.org", "flashed_at": "2025-06-01"}]
  }
]
  • status : ok, degraded, destroyed, hidden ou unknown.
  • city : utilisée seulement si aucune ville de l'équipe n'a ce préfixe ; elle est alors créée (pays « France » par défaut).
  • flashed_by : membres de l'équipe qui l'ont flashé (date du jour par défaut). Les flashs existants sont conservés.
  • Un nom déjà connu dans l'équipe met l'invader à jour. L'import est tout ou rien : la moindre erreur bloque l'enregistrement.
